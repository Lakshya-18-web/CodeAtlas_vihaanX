# CodeAtlas

AI-Powered Codebase Intelligence Platform.

CodeAtlas helps developers understand, explore, and maintain Python repositories through static code analysis, graph intelligence, machine learning-based risk prediction, and retrieval-augmented generation.

## Core Modules

- AST-Based Code Analysis
- Interactive Code Relationship Graph
- ML-Based Risk Prediction
- RAG-Based Codebase Assistant
- Change Impact Intelligence
- Risk Explanation Engine

## Technology Stack

- Backend: Python, FastAPI
- Frontend: React, Vite
- Machine Learning: Scikit-learn, XGBoost
- AI: Gemini API
- Code Analysis: Python AST
- Version Control: Git
